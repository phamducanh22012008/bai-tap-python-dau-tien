
# BAI TAP LAP TRINH PYTHON DAU TIEN

## 1. Gioi thieu
Day la bai tap lap trinh Python dau tien.
Chuong trinh duoc viet de tinh diem trung binh
va xep loai hoc luc cua sinh vien.

## 2. Chuc nang
- Nhap ho ten sinh vien.
- Nhap diem cua 3 mon hoc.
- Tinh diem trung binh.
- Xep loai hoc luc.

## 3. Ngon ngu lap trinh
Python 3

## 4. Cach chay chuong trinh
Buoc 1: Cai dat Python 3.
Buoc 2: Tai file main.py ve may tinh.
Buoc 3: Mo Terminal tai thu muc chua file.
Buoc 4: Chay lenh:

python main.py
